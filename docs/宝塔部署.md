# 宝塔图形化部署
1. 宝塔终端进入 `/www/wwwroot`，用 Git 克隆本仓库的 `main`。不要上传本机的 `data/` 或部署备份。
2. 网站 → Python 项目 → 添加。选择项目专用 Python 3.9+ 环境和 `www` 运行用户，项目路径为 `/www/wwwroot/ai-stock-desk`。
3. 选择命令行启动：`python3 app.py --host 127.0.0.1 --port 8686 --no-monitor`。本项目无第三方依赖。
4. 为 `www` 准备站点目录之外的私有数据目录，用 `AI_STOCK_DATA_DIR` 指向该目录。在宝塔的项目环境变量里自行设置独立强密码 `AI_STOCK_PASSWORD`；不要把值提交到 Git。未设置时无法登录。
5. 保存并启动，在服务器本机确认首页跳转到 `/login`、未登录 API 返回 401。需要域名时，使用带身份验证的 HTTPS 入口，不对公网开放 8686。
