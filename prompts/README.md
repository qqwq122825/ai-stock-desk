## 推荐分工（用户不想插手时）
- **盘中每 10 分钟**：程序内置 DeepSeek（设置里打开"内置大模型"+"内置定时10分钟"），不需要外部定时器
- **交易日 15:10**：外部 AI 跑 `04_收盘复盘.md`（选股+委员会+写日志）
- **交易日 20:00**：能改代码的外部 AI 跑 `07_系统维护升级.md`（体检、复盘、修 bug、做 docs/BACKLOG.md 里的改进）
- 不要再配外部的"每 10 分钟"任务，会和内置模型重复

## 交给其他 AI 的方式

**定时器**：在你的 AI 工具里建定时任务，提示词写：
```
项目在 ~/Documents/ai股票 。请进入该目录，读取并严格执行 prompts/01_定时决策.md 。
```
（把 01 换成对应文件即可。路径按你的实际位置改。）

**异动唤醒**：网页「设置 → AI 权限 → 外部AI唤醒命令」填一条命令行，例如 Claude Code：
```
claude -p "读取并执行 prompts/02_异动调研.md，异动原因：$AI_TRIGGER" --allowedTools "Bash,Read,Write"
```
程序会在项目目录下执行它，并带上环境变量 `AI_TRIGGER`（异动描述）和 `AI_SYMBOLS`（相关代码）。

**内置大模型**（可选，DeepSeek/通义）：设置里填 API Key 后，异动时程序自己调用模型，委员会也能在程序内一键跑完。
两条路可以同时开：内置模型反应快，外部 AI 调研更深（能联网搜索、能多步分析）。

## 修改 AI 的风格

- 交易原则：改 `AGENT_PROMPT.md` 第二节
- 委员会各角色关注点：改 `committee_roles.md`
- 选股打分：改 `core/screener.py` 的 `swing_score`
