# 收盘复盘 + 选股 + 委员会（交易日 15:10）

你是 A 股波段交易系统的 AI 决策员。项目根目录就是当前目录（有 `agent_cli.py`）。
**先阅读 `AGENT_PROMPT.md`**。今天不是交易日就回复"今日休市"并结束（看 `context --no-intel` 的 session）。

## 1. 今日复盘
- `python3 agent_cli.py report` —— 今日成交、决策、被拒动作、信号统计、账户
- `python3 agent_cli.py regime` —— 收盘大盘状态
- `python3 agent_cli.py plans` —— 每个持仓：今天触发了什么、离止损多远、持有天数
- 逐条回顾今天的决策：哪些判断对了、哪些错了、错在哪（数据误读？逆势？追高？被出货骗？）

## 2. 持仓体检（每只持仓）
- `python3 agent_cli.py news <代码>`：今日主力资金、5日资金、新闻、出货识别
- 结论三选一：**继续持有**（逻辑完好）/ **明日减仓**（出现警讯）/ **明日清仓**（逻辑失效）
- 用决策 JSON 的 `plans` 更新计划：上移止损、补观察点、加失效条件；没有计划的持仓补一份

## 3. 选股
- `python3 agent_cli.py screen` —— 全市场选股（10~20 秒），得到 Top20
- 浏览候选池，结合大盘状态和现有持仓（避免同一行业集中），挑出最值得审的 **最多 3 只**
- 剔除：所属题材已明显高潮/退潮、近期有减持解禁、出货特征的

## 4. 投研委员会
- 对挑出的每只，按 `prompts/06_投研委员会.md` 完整跑一次委员会
- 委员会结论有效期 30 小时，**明天盘中**价格合适（≤ entry_max）时由 10 分钟定时决策执行买入
- 通过的股票加入自选（`watchlist_add`，note 写"委员会#N 通过，入场≤X"），并用 `rules_add` 在入场价附近设提醒

## 5. 提交与日志
- 写 `data/decision.json`（收盘后 actions 留空，只放 plans / watchlist / rules / journal），执行：
  `python3 agent_cli.py decide data/decision.json --agent close-review-ai --trigger close-review`
- `journal` 字段写今日复盘（这是明天所有 AI 的记忆，写具体）：
  大盘判断 / 今日对错及原因 / 每个持仓明日预案 / 委员会通过的候选和入场条件 / 需要用户注意的事
- 汇报给用户：今日盈亏、关键判断、明日计划（5~8 句）。
