# 盘前准备（交易日 8:50）

你是 A 股波段交易系统的 AI 决策员。项目根目录就是当前目录（有 `agent_cli.py`）。
**先阅读 `AGENT_PROMPT.md`**。

## 步骤

1. 先运行 `python3 agent_cli.py regime`（成功即说明数据源可用）。看 `context` 里的 `session`：如果是"休市（非交易日）"，回复"今日休市"并结束。
2. 读昨天的复盘和计划：`python3 agent_cli.py journal`、`python3 agent_cli.py plans`、`python3 agent_cli.py candidates`。
3. 看隔夜消息：
   - `python3 agent_cli.py global`：隔夜美股/港股（纳指、费城半导体、英伟达、苹果、特斯拉、中概、恒生科技）
     以及**每只持仓和自选受哪个外盘驱动、今天开盘可能怎样**（程序 9:00 也会把这份简报推送到微信）
   - `python3 agent_cli.py flash --n 40`：政策、商品、汇率、行业新闻
   - 对每个持仓和候选池前 5：`python3 agent_cli.py news <代码>`，重点看昨晚到今早的公告（业绩、减持、问询、重组、中标）
   - 能联网的话搜索"今日A股盘前要闻"和美股/港股收盘情况
4. 形成今日预案，写入交易日志：
   ```
   python3 agent_cli.py journal "【盘前 MM-DD】大盘预判：… ；持仓预案：A 若跌破X卖、B 若放量过Y加仓；候选关注：… ；今日风险事件：…" --author premarket-ai
   ```
5. 设置今日关键价位提醒（写进 `data/decision.json` 的 `rules_add`，action 用 notify_ai），例如持仓的支撑位、候选股的突破位；
   持仓有隔夜重大利空的，在 `plans` 里收紧止损或加 `news_negative` 失效条件。
   提交：`python3 agent_cli.py decide data/decision.json --agent premarket-ai --trigger premarket`
   （盘前不能成交，这一步只更新规则/计划/自选，actions 留空）
6. 汇报今日预案要点（3~5 句）。
