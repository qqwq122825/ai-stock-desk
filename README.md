# AI 量化决策台（A股 · 波段）

```
全市场选股 ─→ 11人投研委员会 ─→ 风控/大盘择时 ─→ 模拟盘自动成交 / 实盘人工确认
     ↑              ↑                                   ↓
 大盘情绪择时   消息面+资金面                      持仓计划自动盯盘
                                                        ↓
 实时监控(3秒五档) → 规则/指标策略/出货识别/计划触发 → 微信推送 → 唤醒 AI 调研
```

**零第三方依赖**，Mac 自带 `python3`（3.9+）即可。

## 快速开始

双击 `start.command`（阻止睡眠 + 启动 + 打开浏览器），或：
```bash
cd ~/Documents/ai股票 && caffeinate -i python3 app.py     # 打开 http://127.0.0.1:8686
```
1. 「设置」→ 填 PushPlus Token / Server酱 → 发送测试消息
2. 「设置」→ 交易范围：勾选你已开通的板块（默认 主板+ETF+北交所）
3. 「选股」→ 立即选股，看大盘状态和候选池
4. 把 `prompts/` 里的提示词交给其他 AI 的定时器（见 [prompts/README.md](prompts/README.md)）
5. 可选：「设置」填 DeepSeek/通义 API Key（内置大模型：异动即时决策、委员会一键跑）

## AI 怎么工作

| 场景 | 谁触发 | 提示词 |
|---|---|---|
| 盘中每 10 分钟 | 外部 AI 定时器 | `prompts/01_定时决策.md` |
| 异动（规则/强信号/计划触发） | 程序自动：内置模型 和/或 唤醒外部 AI 命令 | `prompts/02_异动调研.md` |
| 盘前 8:50 / 收盘 15:10 / 周末 | 外部 AI 定时器 | `03` / `04`（含选股+委员会）/ `05`（回测研究） |
| 建仓/加仓 | **必须**先过委员会 | `prompts/06_投研委员会.md` + `committee_roles.md` |

所有 AI 的总纲：[AGENT_PROMPT.md](AGENT_PROMPT.md)。AI 之间靠**交易日志**（`journal`）传递记忆。

### 11 人投研委员会
5 分析师（技术/资金/消息/基本面/情绪题材，并行独立）→ 多头 ⇄ 空头 辩论 2 轮 → 研究主管裁判 → 交易员（入场/止损/目标/仓位）
→ 风控官（一票否决）→ 组合经理拍板并写持仓计划。
- 内置模式：`committee run <代码>`，程序调用大模型跑完
- 外部模式：`committee start` → 外部 AI 逐个角色提交 → `committee final`（能开子代理的 AI 可并行）
- 每个角色的立场都存库，`committee stats` 统计**哪个角色判断准**

### 持仓计划（买入后盯什么）
建仓成交时自动生成：买入逻辑、止损价、目标价、移动止盈、最长持有天数（时间止损）、**失效条件**
（收盘跌破/盘中跌破/均线破位/主力连续流出/出货特征/利空）、观察点。监控自动检查 → 推送 + 唤醒 AI 复核；
模拟盘跌破止损自动卖，实盘生成待确认卖单。

### A 股特色：借利好出货 / 利空洗盘识别
利好 + 高开或冲高回落 + 放量 + **价涨但主力净流出** + **小单（散户）净流入** + 位置高 → 出货预警；
利空 + 不跌或低开回升 + 主力净流入 → 洗盘关注。AI 提示词也明确：**看市场对消息的反应，而不是消息本身**。

## 外盘联动
A 股科技股常跟随隔夜美股对应板块：半导体 ↔ 费城半导体/英伟达，算力/光模块 ↔ 英伟达/纳指，消费电子 ↔ 苹果，
新能源车 ↔ 特斯拉，互联网 ↔ 中概金龙/恒生科技。系统按股票所属行业自动匹配，
交易日 9:00 推送盘前简报（外盘 + 受影响的持仓/自选），早盘外盘大跌/大涨会轻微修正大盘状态（13:00 后不再修正）。
收盘后选股不使用外盘数据（避免重复计算）。

## 新手默认设置
持仓 ≤3 只 · 每日 ≤4 笔 · 当日亏 3% 熔断 · 当日涨超 5% 不追 · 置信度 ≥0.65 · 只做主板+ETF（不碰北交所/创业板/科创板）·
成交额 ≥2 亿 · 不买上市不满一年的次新股 · 冰点期不开新仓 · 金字塔最多加 1 次 · "关注"类信号不推送（防刷屏）。
都可以在网页「设置」里改。

## 仓位管理（反马丁）

- **按单笔风险定仓**（默认）：股数 = 总资产 × 2% ÷ (买入价 − 止损价)。止损越远买得越少，每笔最坏亏损事先确定。
  例：1 万 × 2% = 200 元，买入 10 元、止损 9.3 元 → 最多 285 股 → 取整 200 股。也可在设置里切回"按总资产百分比"。
- **禁止马丁格尔**：浮亏时加仓（补仓摊平）一律拒绝。
- **金字塔加仓**：浮盈 ≥ 8% 才能加，每次加上次的一半，最多 2 次，加仓后止损自动上移到保本；加仓也要过委员会。
- 持仓计划的止损 AI 只能上移；你可以在总览的「改止损」手动调整。
- 1 万资金的现实：2% 风险下止损 −7% 时单笔约 2,860 元，股价 28 元以上的票买不了一手（除非止损设得更近）。

当日亏 3% 熔断 · 涨幅 >5% 不追 · 禁 ST · T+1 · 一手 · 涨停买不进/跌停卖不出 · 计划止损

## 实盘
- `manual`（默认）：待确认订单 → 微信 → 网页确认 → 你在券商 App 下单 → 回填成交价
- `qmt`：迅投 miniQMT（Windows，`pip install xtquant`）。**未在真实券商环境实测，首次请用 1 手验证。**
  通过券商 API 程序化下单按现行规定需向券商报备。
